## Rules (keep these)

- The rules in the repository root `AGENTS.md` apply. In short: **never commit, push, open pull requests or manage branches.** Leave changes uncommitted, list the files you changed, and suggest a commit message.
- **The repository is public.** Use only made-up content, placeholder data and publicly licensed assets. Never add client material, confidential information or personal data.
- Only create or edit files inside this folder.
- Never write real API keys or secrets into files. Read them from `.env`, and list new variables in `.env.example` with placeholder values.
- Don't add files that `.gitignore` excludes to the repository, and don't remove entries from `.gitignore` without asking.
