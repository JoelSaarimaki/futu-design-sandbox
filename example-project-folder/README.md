# Example project folder

A template for your own sandbox project. Copy this folder, rename it, and replace the content below with your project's details.

**Owner:** Your Name
**Status:** Exploring / In progress / Done

## What is this?

One or two sentences about the idea, e.g.
*"A clickable prototype of a mobile onboarding flow, built with an AI coding assistant to test whether three steps are enough."*

## How to run it

The simplest case: open `index.html` in your browser.

If your project needs a dev server or packages, write the exact commands here, e.g.
```bash
npm install
npm run dev
```

If it needs API keys, copy `.env.example` to `.env` and fill in your own values. `.env` is ignored by Git.

## What's in this folder

| File            | Purpose                                                              |
| --------------- | -------------------------------------------------------------------- |
| `README.md`     | This file: what the project is and how to run it. For humans.        |
| `AGENTS.md`     | Context and rules for AI tools working in this folder.               |
| `.gitignore`    | Files Git should not track in this folder (secrets, exports, etc.).  |
| `.env.example`  | Names of the secrets/settings the project needs, without real values. |
| `index.html`    | A minimal starting page. Replace it with your own work.              |
